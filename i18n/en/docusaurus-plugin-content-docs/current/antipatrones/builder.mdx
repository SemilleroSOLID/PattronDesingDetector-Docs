# Builder

## How a "fluent method" is counted

`fluentMethodCount` doesn't count just any method that returns `this`. It
counts only **instance** methods that:

- Declare their own class's type as the return type, and
- Contain a `return this;` in the body, where `this` is the **entire**
  expression of the `return` — `return this.field;` doesn't count.

The check doesn't enter anonymous classes or lambdas, because `this`
means something else there. This criterion exists on purpose: without the
"`this` as the entire expression" requirement, any class with methods
that return copies (for example Gson's `Excluder.withVersion()`) would
get marked as a Builder without being one.

## Evidence that it's already implemented (`detected`)

Marked `detected` when the class has **at least 1 fluent method** plus a
`build()` method that returns the target type.

## Evidence that it's a candidate (`potential`)

If not `detected`, it's marked as a candidate when:

- It has **2 or more fluent methods** but doesn't have `build()` yet, or
- It has the **`Builder` suffix** in the class name and at least **1**
  fluent method, without `build()` yet.

## Builder as a static nested class

If the analyzed class doesn't form a complete Builder on its own, the
detector also looks for a builder declared as a **static nested class** —
the classic Joshua Bloch pattern. It's only accepted if the nested
class's construction method returns the outer class; `static` is required
because a non-static inner builder can't be instantiated on its own. The
evidence is attributed to the outer class either way.

`hasBuilderSuffix` is always computed on the **analyzed** class, never on
the nested one — this is intentional, that field doesn't change meaning
depending on where the builder was found.

## AI suggestion

If the class is only missing the `build()` method (it already has 2+
fluent methods), the instruction to the AI is precise: generate **only**
that method. In any other candidacy case, a more complete implementation
of the pattern is requested.
